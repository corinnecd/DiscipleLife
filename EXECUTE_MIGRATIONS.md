# Instructions pour exécuter les migrations SQL

## Migrations créées pour les objectifs 4 à 12

Les fichiers suivants ont été créés dans `sql/migrations/` :

1. **019_objectif4_plateforme_missionnaire.sql** - Objectif 4 : Plateforme missionnaire
2. **020_objectif5_connexions_reseau.sql** - Objectif 5 : Connexions (mariage, affaires)
3. **021_objectif6_influence_disciples.sql** - Objectif 6 : Influence et disciples
4. **022_objectif7_assistance_necessiteux.sql** - Objectif 7 : Assistance aux nécessiteux
5. **023_objectif8_protection_ames.sql** - Objectif 8 : Protection des âmes
6. **024_objectif9_evaluation_leaders.sql** - Objectif 9 : Évaluation des leaders
7. **025_objectif10_vrais_disciples.sql** - Objectif 10 : Identifier les vrais disciples
8. **026_objectif11_affermissement_convertis.sql** - Objectif 11 : Affermissement 3 mois
9. **027_objectif12_remplir_culte.sql** - Objectif 12 : Remplir les cultes

## Comment exécuter dans Supabase

1. Ouvrez Supabase Dashboard
2. Allez dans SQL Editor
3. Exécutez chaque fichier SQL dans l'ordre (019, 020, 021, etc.)
4. Vérifiez qu'il n'y a pas d'erreurs

## Ordre d'exécution recommandé

Exécutez les migrations dans l'ordre numérique pour respecter les dépendances entre tables.
